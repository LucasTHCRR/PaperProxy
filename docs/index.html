PaperProxy Plugin Checker

NOT AN OFFICIAL PAPER PROJECT · NOT AFFILIATED WITH PAPERMC

Moving from Velocity, BungeeCord or Waterfall? Drop your proxy plugins below and see right away whether they run on PaperProxy.

Works runs on PaperProxy Works with limits some features are ignored Does not work needs things PaperProxy cannot offer

Velocity plugins

Run natively. PaperProxy is a Velocity fork, the full Velocity API is there.

BungeeCord plugins

Run through a built-in layer that implements the original BungeeCord API.

What is checked

Plugin type, required Java version and use of BungeeCord internals such as raw packets or Netty.

Download PaperProxy GitHub Discord

This is a static check of the plugin's code, so "Works" is a strong hint, not a guarantee. Wrong result? Tell us on Discord or open an issue.
